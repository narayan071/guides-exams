Ch 1: Functional Units, Architecture Models, Buses & CPU Registers High-Yield

Start Here Computer Architecture = programmer-visible attributes (ISA, registers, addressing modes, data types); Computer Organization = physical hardware implementation (control signals, cache size, bus width, ALU design). Two chips can share the same Architecture (x86-64) with totally different Organization!

Von Neumann vs Harvard & Flynn's Classification

Von Neumann vs Harvard Architecture

  • Von Neumann (Princeton): Stored-program concept (1945) — single shared memory & shared bus hold both instructions and data. Causes the Von Neumann Bottleneck (CPU cannot fetch instruction & read/write data simultaneously).
  • Pure Harvard: Physically separate Instruction Memory/Bus & Data Memory/Bus → parallel access (fast, deterministic; used in DSPs/embedded MCUs).
  • Modified Harvard (Modern CPUs): Unified main RAM outside CPU, but split L1 Instruction Cache (I-Cache) & Data Cache (D-Cache) inside CPU!

Flynn's Taxonomy (Instruction × Data Streams)

  • SISD: Classic single-core CPU (1 instruction, 1 data stream).
  • SIMD: Vector processors, GPUs, CPU AVX extensions (same instruction applied across array of data in parallel).
  • MISD: Multiple ALUs on 1 data stream (theoretical / specialized fault-tolerant flight controllers).
  • MIMD: Modern multicore CPUs, symmetric multiprocessors (SMP), distributed clusters.

Essential CPU Registers

  • PC (Program Counter)Holds memory address of the next instruction to be fetched.
  • IR (Instruction Register)Holds the currently fetched/decoded instruction opcode & operands.
  • MAR (Mem Address Reg)Receives address from PC/operand unit and drives the Address Bus.
  • MDR / MBR (Data Reg)Two-way buffer sitting directly on the Data Bus (holds read/written word).
  • AC (Accumulator)Implicit ALU input/output register in 1-address architectures.
  • SP & PSW (Flags)SP tracks stack top; PSW stores status flags: Zero (Z), Carry (C), Sign (N/S), Overflow (V/O), Interrupt (I).
Address Width Formula Trap If a system has 16 GB RAM that is word-addressable (1 word = 4 bytes) instead of byte-addressable, total addressable units = 16 GB / 4 B = 4 G = 232 words → requires 32 address bits, NOT 34! Always check byte- vs word-addressable!

Ch 2: Number Systems, 2's Complement, Overflow, IEEE 754 & Codes Numerical Core

Start Here Modern CPUs perform subtraction via 2's complement addition (A - B = A + (~B + 1)), represent real numbers using IEEE 754, and protect memory against bit flips using Parity / Hamming ECC.

Signed Integer Representations (n bits)

RepresentationRange (for n bits)8-bit RangeZerosExam Notes
Sign-Magnitude-(2n-1 - 1) to +(2n-1 - 1)-127 to +1272 (+0, -0)MSB = sign (0 pos, 1 neg); awkward hardware addition.
1's Complement-(2n-1 - 1) to +(2n-1 - 1)-127 to +1272 (00000000, 11111111)Bitwise NOT; requires end-around carry add!
2's Complement-2n-1 to +(2n-1 - 1)-128 to +1271 (0 unique!)Invert bits + add 1. Asymmetric negative limit (-128 = 10000000 has no +128!).

2's Complement Arithmetic Overflow Rule (CRITICAL!): Overflow occurs IF AND ONLY IF two operands of the same sign produce a sum of the opposite sign (equivalently: Carry_into_MSB XOR Carry_out_of_MSB == 1). A final Carry-out C_out = 1 in 2's complement does NOT imply overflow (e.g. (+5) + (-3) = +2 produces C_out = 1 with zero overflow!).

Special Binary Codes & Error Correction (Gray, BCD, Excess-3, Hamming)

  • BCD (8421 Code)Each decimal digit 0–9 encoded in 4 bits (1010–1111 unused/invalid!). Weighted code (8,4,2,1).
  • Excess-3 CodeBCD + 3 (0011). Non-weighted and self-complementing (1's comp = 9's comp!).
  • Gray CodeUnit-distance / cyclic code: consecutive numbers differ by 1 bit (minimizes glitch in K-maps & sensors). Gn = Bn, Gi = Bi+1 ⊕ Bi.
  • Hamming ECC (SEC)Redundant parity bits r at positions 20, 21, 22... satisfying 2r ≥ m + r + 1. E.g. 8 data bits need 4 parity bits (24 = 16 ≥ 8+4+1 = 13). Distance d: detects d-1, corrects ⌊(d-1)/2⌋ errors!

Ch 3: Digital Logic Gates, Combinational & Sequential Circuits (Flip-Flops)

Start Here Combinational circuits (Adders, MUX, Decoders) depend ONLY on present inputs; Sequential circuits (Flip-Flops, Counters, Shift Registers) contain clock-driven memory elements whose output depends on present input + previous stored state.

Logic Gates, De Morgan & Universal Gates

  • Universal GatesNAND and NOR alone can construct ALL gates (NOT, AND, OR, XOR).
  • XOR (A ⊕ B)Outputs 1 when inputs differ (Odd-1s parity checker). Needs 4 NAND or 5 NOR gates!
  • XNOR (A ⊙ B)Outputs 1 when inputs are identical (Equality / Comparator).
  • De Morgan's Laws(A + B)' = A' · B' (NOR = Bubbled AND); (A · B)' = A' + B' (NAND = Bubbled OR).
  • SOP vs POSSOP = Sum of Minterms (NAND-NAND); POS = Product of Maxterms (NOR-NOR).
  • K-Map GroupingAdjacent cells grouped in powers of 2 (1, 2, 4, 8); Don't Care (d/X) acts as 1 or 0 to enlarge groups.

Ch 4: Instruction Formats, Addressing Modes & Control Unit (RISC vs CISC)

Start Here Expect questions calculating Effective Address (EA), comparing 0/1/2/3-address instructions, solving expanding-opcode problems, and distinguishing Hardwired vs Microprogrammed Control Units.

Instruction Execution Cycle & Format Types

  • 4 Sub-cycles: Fetch (MAR←PC, load IR, increment PC) → Decode (CU decodes opcode/mode) → Execute (ALU/Mem/Branch) → Interrupt (check pending maskable/NMI requests, save context).
  • 3-Address (ADD R1, R2, R3): Fewest instructions, widest opcode+address word.
  • 2-Address (ADD R1, R2): R1 ← R1 + R2 (destroys 1 source operand; x86 style).
  • 1-Address (LOAD A; ADD B): Uses implicit Accumulator (AC); 1 explicit memory/reg field.
  • 0-Address (Stack / RPN): Arithmetic ops (ADD, MUL) pop top 2 items from stack and push result — zero address fields needed in ALU instructions (only PUSH addr / POP addr carry addresses).

Control Unit Design & RISC vs CISC Comparison

Hardwired CU vs Microprogrammed CU

  • Hardwired CU: Generates control signals via fixed combinational gates/FSM. Fastest, minimal chip overhead for small ISAs (RISC), hard to patch/extend.
  • Microprogrammed CU: Stores microinstructions inside fast Control Memory (ROM); flexible to implement complex instructions (CISC) & fix microcode bugs!
  • Horizontal vs Vertical Microprogramming: Horizontal = 1 bit per control signal (wide word, parallel, NO external decoder, faster); Vertical = encoded fields (narrow word, needs decoder, slower!).

RISC vs CISC Architecture

  • RISC (ARM, RISC-V, MIPS): Fixed-length instructions (32-bit), Load/Store architecture (ONLY Load/Store touch memory!), few simple addressing modes, large register file (32+ GPRs), Hardwired CU, deep pipelining (~1 CPI!).
  • CISC (x86 / VAX): Variable-length instructions (1–15 bytes), ALU instructions access memory directly, rich complex addressing modes, smaller register set, Microprogrammed CU, higher CPI.
PC-Relative Jump Trap during Fetch! Remember: CPU increments PC ← PC + instr_size during Instruction Fetch (BEFORE Execute!). So when calculating Branch Target = PC + Offset, use the updated PC pointing to the instruction immediately AFTER the branch!

Ch 5: CPU Performance, Pipelining, Hazards & ILP Exam Favorite

Start Here Pipelining overlaps execution of multiple instructions like an assembly line. It boosts Instruction Throughput (ideal CPI → 1), while individual instruction latency never decreases (actually slightly rises due to inter-stage latch overhead!).

CPU Iron Law, Amdahl's Law & Pipeline Speedup

  • CPU Execution TimeTime = IC × CPI × Tclk = (IC × CPI) / Freq. (Instruction Count × Cycles Per Instr × Clock Period).
  • Amdahl's LawS = 1 / ((1 − f) + f / s). Even if speedup s → ∞, max overall speedup caps at 1 / (1 − f) (serial bottleneck!).
  • Pipeline Cycle Time (τ)In a k-stage pipeline: τ = max(stage_delays) + latch_delay (clock cannot run faster than the slowest stage!).
  • Total Time & Speedupn instructions take (k + n − 1) × τ. Ideal speedup S → k as n → ∞! (Real CPI = 1 + stall_cycles_per_instr).

Hazard TypeRoot CauseHardware / Compiler Fixes
1. StructuralTwo instructions need the same hardware resource in the same cycle (e.g. unified L1 cache for IF + MEM).Split L1 I-Cache & D-Cache (Harvard L1!), duplicate functional units, or insert stall cycle.
2. Data — RAW (True)Read After Write: Instruction i+1 reads register written by in-flight i (e.g. ADD R1,R2,R3; SUB R4,R1,R5).Operand Forwarding (Bypassing) feeds ALU/MEM output directly back to next EX stage. (Trap: Load followed immediately by ALU consumer — Load-Use Hazard — STILL requires 1 stall bubble even with forwarding!).

Two Huge Pipelining Exam Traps 1) Comparing MIPS across RISC vs CISC is misleading because RISC executes more simple instructions per task (higher IC, higher MIPS, yet may finish slower or faster!). Always compare Execution Time!
2) In a 5-stage pipeline (IF-ID-EX-MEM-WB), ADD→SUB RAW hazard causes 0 stalls with forwarding, whereas LW R1, 0(R2) followed by ADD R3, R1, R4 causes 1 stall cycle even with forwarding because RAM read finishes at the end of MEM!

Cache Mapping Techniques (Address Bits Breakdown)

Given Byte-Addressable Main Memory size = 2A bytes (A address bits), Cache Data size = C bytes, Cache Line/Block size = B = 2b bytes → Total Cache Lines L = C / B:

A-bit Physical Addr:  [   Tag Bits (A - s - b)   |   Set/Line Index (s bits)   |   Block Offset (b bits)   ]
Mapping ModeLines / Set (k)Sets (S = L/k) & Index (s)Comparators & Tradeoff
1. Direct Mappedk = 1S = L; s = log2(L)1 comparator (fastest, lowest cost), but blocks mapping to same line mod L thrash → high conflict misses!
2. Fully Associativek = LS = 1; s = 0 Index bits!L comparators (expensive Content-Addressable Memory / CAM). Zero conflict misses; longest Tag!
3. k-Way Set Associativek (e.g. 2, 4, 8)S = L / k; s = log2(S)k comparators in parallel. Best real-world balance of hit rate & speed! Increasing k → 2k halves sets (s - 1) and adds +1 bit to Tag!

Worked Example: 4 GB RAM (32-bit addr), 64 KB 4-way set-associative cache, 64 B block size → Offset b = log2(64) = 6 bits; Total lines L = 64 KB / 64 B = 1024; Sets S = 1024 / 4 = 256 = 28 → Index s = 8 bits; Tag = 32 - 8 - 6 = 18 bits!

AMAT (Average Memory Access Time), Write Policies & 3C Misses

AMAT & Cache Policies

  • Hierarchical (Sequential) Access: CPU always checks Cache (Tc); on miss (1−h), fetches block from RAM (Tm):
    AMAT = Tc + (1 − h) × Tm (or h·Tc + (1−h)·(Tc + Tm)).
  • Simultaneous Access: Both queried at t=0: AMAT = h·Tc + (1−h)·Tm (check question wording: sequential vs simultaneous!).
  • Write-Through: Writes to Cache AND RAM simultaneously (consistent, high bus traffic; paired with Write Buffer & No-Write-Allocate).
  • Write-Back: Updates Cache ONLY & sets Dirty Bit (Modified=1); flushes to RAM only when line is evicted (fast writes, low bus traffic; uses Write-Allocate).

3 C's Cache Misses & RAM Organization

  • Compulsory (Cold) Miss: Very first reference to a block (cannot avoid; larger blocks prefetch neighbors to reduce count).
  • Capacity Miss: Working set exceeds total cache size (only increasing cache capacity fixes).
  • Conflict (Collision) Miss: Multiple blocks contend for same set even though cache isn't full (increase associativity k to reduce).
  • RAM Chip Count Formula: Required M × W using m × w chips = ⌈M / m⌉ × ⌈W / w⌉ chips! (Add decoder lines for row chip-select).
  • Memory Interleaving: Low-order interleaving spreads consecutive addresses across k independent banks (uses LSB bits for Bank ID) → parallel burst throughput! High-order puts contiguous ranges per module.

Start Here High-speed NVMe SSDs and 10 Gbps NICs cannot waste CPU cycles moving bytes individually. Know why DMA Cycle Stealing beats Interrupt-driven & Programmed I/O, how Memory-Mapped I/O differs from Port I/O, and how TLB + MMU accelerate paging!

I/O Data Transfer Modes Comparison

ModeHow Data MovesCPU Involvement & Use Case
1. Programmed I/O (Polling)CPU executes status-check loop continuously until device ready, then moves word.100% CPU wasted busy-waiting. Simple legacy debug / low-rate sensors only.

  • DMA Transfer ModesBurst Mode (DMAC holds bus for full block — stalls CPU) • Cycle Stealing (steals 1 mem cycle at a time — smooth CPU progress!) • Transparent (uses bus only when CPU is idle).

Part A: Core Architecture, Logic & Data Representation (Q1–Q12)

Q1 Which architecture physically separates instruction and data memory/buses, and how do modern x86/ARM CPUs adopt it at L1?
A) Pure Von Neumann everywhere   B) Harvard architecture; modern CPUs use Modified Harvard with split L1 I-Cache & D-Cache   C) MISD; shared L1 cache   D) SISD; dual BIOS   E) Ring architecture
Answer: B) Harvard / Modified Harvard (split L1 I-Cache & D-Cache).
Main DRAM stays unified (Von Neumann outward), while splitting L1 cache into I-Cache + D-Cache allows the Fetch and Memory stages of a CPU pipeline to operate simultaneously without structural hazards!
Q2 Which CPU register directly drives the Memory Address Bus during Instruction Fetch and Data Load?
A) IR   B) MDR   C) MAR   D) AC   E) PSW
Answer: C) MAR (Memory Address Register).
PC copies the next address into MAR, which places it onto the unidirectional Address Bus. Returned data arrives on the Data Bus into MDR, then moves to IR!
Q3 A 32-bit integer 0xAABBCCDD is stored starting at byte address 0x1000 on a Little-Endian processor (e.g. x86-64). What byte sits at address 0x1000?
A) 0xAA   B) 0xBB   C) 0xCC   D) 0xDD   E) 0x00
Answer: D) 0xDD (Least Significant Byte at Lowest Address).
Little-Endian puts the "little end" (LSB = 0xDD) first at 0x1000, then 0xCC, 0xBB, 0xAA. Big-Endian (Network byte order) stores MSB 0xAA at 0x1000.
Q4 What is the exact signed integer range representable by an 8-bit 2's complement register, and how many zeros exist?
A) -127 to +127, 2 zeros   B) -128 to +127, 1 unique zero   C) -128 to +128, 1 zero   D) 0 to 255, 1 zero   E) -127 to +128, 2 zeros
Answer: B) -128 to +127 (-27 to +(27-1)), 1 unique zero.
10000000 represents -128; 00000000 is unique 0; 01111111 is +127.
Q5 In IEEE 754 Single Precision (32-bit) floating-point representation, what are the bit widths of Sign, Exponent, Mantissa, and the Exponent Bias?
A) 1, 7, 24, Bias 63   B) 1, 8, 23, Bias 127   C) 1, 11, 52, Bias 1023   D) 1, 8, 23, Bias 128   E) 2, 8, 22, Bias 127
Answer: B) 1 Sign, 8 Exponent, 23 Mantissa, Bias = 127.
Option C gives IEEE 754 Double Precision (64-bit: 1 + 11 + 52, Bias 1023).
Q6 How many Half Adders and extra gates are minimally needed to build a single-bit Full Adder?
A) 1 Half Adder + 1 AND   B) 2 Half Adders + 1 XOR   C) 2 Half Adders + 1 OR gate   D) 3 Half Adders + 1 NOT   E) 1 Full MUX only
Answer: C) 2 Half Adders + 1 OR gate.
HA1 adds A, B → (S1, C1); HA2 adds S1, C_in → (Sum, C2); final C_out = C1 OR C2.
Q7 How many minimum JK Flip-Flops are required to build a MOD-20 synchronous binary counter?
A) 3   B) 4   C) 5   D) 10   E) 20
Answer: C) 5 flip-flops.
Needs 2n ≥ 20 → n = 4 gives only 16 states (0–15), whereas n = 5 gives 32 ≥ 20 states (with 12 unused states).
Q8 Which Boolean pair acts as Universal Gates capable of implementing any combinational logic function alone?
A) AND & OR   B) XOR & XNOR   C) NAND & NOR   D) NOT & XOR   E) MUX & OR only
Answer: C) NAND and NOR.
Both are functionally complete individually: tying inputs gives NOT, complementing outputs yields AND/OR!
Q9 How many redundant parity bits (r) are needed by Hamming SEC code to protect an 8-bit data byte against any single-bit error?
A) 1   B) 3   C) 4   D) 5   E) 8
Answer: C) 4 parity bits.
Formula: 2r ≥ m + r + 1. For m = 8: test r=3 → 8 < 12 (fails); test r=4 → 16 ≥ 8 + 4 + 1 = 13 (passes! Total 12-bit codeword).
Q10 Which addressing mode computes Effective Address = PC + Signed Offset, making loop/branch code independent of where the OS loads it in RAM?
A) Direct Absolute   B) Immediate   C) Register Indirect   D) PC-Relative   E) Double Indirect
Answer: D) PC-Relative addressing.
Used heavily in conditional branches (BEQ, JNE) to enable Position-Independent Code (PIC) and shared libraries!
Q11 In a CPU capable of Out-of-Order execution, what hardware mechanism eliminates false WAR (Anti-) and WAW (Output-) data dependencies?
A) Larger L3 Cache   B) Register Renaming   C) Delayed Branching   D) Split I/D Cache   E) Memory Interleaving
Answer: B) Register Renaming.
WAR and WAW arise solely from reusing architectural register names (R1, R2), not true data flow. Mapping architectural names to distinct physical reservation registers eliminates them!
Q12 Why does Horizontal Microprogramming execute faster than Vertical Microprogramming?
A) Uses smaller control ROM   B) Each microinstruction bit drives control lines directly in parallel without needing slow external decoders   C) Only works on RISC   D) Encodes fields in compact 4-bit codes   E) Requires 2 cycles per micro-op
Answer: B) Wide uncompressed control word with no decoder delay & high parallelism.
Vertical uses compact encoded fields that save ROM space but require hardware decoders before control signals trigger.

Part B: Scale 2 Numericals & Design Scenario Problems (Q13–Q24)

Q13 · Numerical A server supports 16 GB of physical memory that is byte-addressable. What is the minimum number of bits required on the CPU Address Bus (MAR width)?
A) 30 bits   B) 32 bits   C) 34 bits   D) 36 bits   E) 40 bits
Answer: C) 34 bits.
16 GB = 16 × 230 B = 24 × 230 = 234 bytes → requires 34 address lines! (Note: 32 bits addresses only 4 GB).
Q14 · Numerical How many 2K × 4 RAM chips are needed to design a 16K × 8 main memory module?
A) 8   B) 12   C) 16   D) 24   E) 32
Answer: C) 16 chips.
Depth rows = 16K / 2K = 8; Width columns = 8 bits / 4 bits = 2. Total = 8 × 2 = 16 chips (driven by a 3-to-8 decoder selecting the active row!).
Q15 · Numerical A CPU uses 32-bit physical addresses with a 64 KB, 4-way set-associative cache whose block size is 64 Bytes. How many bits are in the Tag, Set Index, and Block Offset fields respectively?
A) 16, 10, 6   B) 18, 8, 6   C) 20, 6, 6   D) 18, 10, 4   E) 26, 0, 6
Answer: B) Tag = 18, Set Index = 8, Block Offset = 6.
Step 1: Block Offset = log2(64) = 6 bits.
Step 2: Total lines = 64 KB / 64 B = 1024 lines.
Step 3: 4-way sets = 1024 / 4 = 256 = 28 → Index = 8 bits.
Step 4: Tag = 32 - 8 - 6 = 18 bits!
Q16 · Numerical In a sequential (hierarchical) cache lookup system, Cache access time = 4 ns, Main Memory access time = 60 ns, and Hit Ratio = 90% (0.9). What is the AMAT?
A) 6.0 ns   B) 9.6 ns   C) 10.0 ns   D) 14.0 ns   E) 54.0 ns
Answer: C) 10.0 ns.
Hierarchical AMAT = Tcache + (1 − h) × Tmem = 4 + (0.10 × 60) = 4 + 6 = 10 ns. (Notice: in a simultaneous parallel model where 0.9×4 + 0.1×60 = 9.6 ns, parallel saves checking time on a miss — always watch "hierarchical/look-aside" vs "simultaneous" wording!).
Q17 · Numerical A non-pipelined processor takes 25 ns per instruction. It is split into a 5-stage pipeline with unequal stage delays: 4 ns, 5 ns, 7 ns, 4 ns, 5 ns plus 1 ns inter-stage latch delay. What is the pipeline's clock cycle time (τ) and steady-state speedup (n → ∞)?
A) 5 ns; 5×   B) 7 ns; 3.57×   C) 8 ns; 3.125×   D) 6 ns; 4.16×   E) 26 ns; 0.96×
Answer: C) τ = 8 ns; steady-state Speedup = 3.125×.
Clock must accommodate slowest stage + latch: τ = max(4,5,7,4,5) + 1 = 7 + 1 = 8 ns (125 MHz)! As n → ∞, pipelined time per instruction = τ = 8 ns → Speedup = 25 / 8 = 3.125× (notice why unbalanced stages cut speedup below ideal 5×!).
Q18 · Scenario An instruction sequence in a classic 5-stage RISC pipeline (IF-ID-EX-MEM-WB) WITH full operand forwarding runs:
1) LW R1, 0(R2)
2) ADD R3, R1, R4
3) SUB R5, R3, R6
How many total stall cycles (bubbles) are inserted?
A) 0 stalls   B) 1 stall   C) 2 stalls   D) 3 stalls   E) 4 stalls
Answer: B) 1 stall cycle.
Between LW (1) and ADD (2), R1 arrives only at the END of MEM stage of LW, too late for ADD's EX stage without stalling → 1 load-use stall bubble! Then ADD's result forwards directly to SUB's EX stage with 0 stalls!
Q19 · Scenario On a system with a 1-level Page Table, TLB hit time = 10 ns, RAM access time = 90 ns, and TLB Hit Ratio = 80%. Ignoring page faults, what is the Effective Memory Access Time (EMAT)?
A) 100 ns   B) 118 ns   C) 126 ns   D) 180 ns   E) 190 ns
Answer: B) 118 ns.
On TLB Hit (80%): TLB (10) + Data RAM (90) = 100 ns.
On TLB Miss (20%): TLB (10) + PageTable RAM (90) + Data RAM (90) = 190 ns.
EMAT = 0.8(100) + 0.2(190) = 80 + 38 = 118 ns!
Q20 · Scenario A banking ETL workload spends 60% of its execution time doing database vector hashing (parallelizable) and 40% in single-threaded log commit. Even if you upgrade the parallel hashing hardware to be 1000× faster (s → ∞), what is the theoretical ceiling on overall speedup (Amdahl's Law)?
A) 1000×   B) 10×   C) 5×   D) 2.5×   E) 1.5×
Answer: D) 2.5× ceiling.
Max Speedup = 1 / (1 − f) = 1 / (1 − 0.60) = 1 / 0.40 = 2.5×! The 40% serial portion caps speedup no matter how fast the parallel part gets.
Q21 · Scenario A 10 Gbps network card delivers 256 KB packet buffers continuously to RAM. Which I/O method avoids both 100% CPU busy-waiting and stalling the CPU for the whole block duration while transferring bytes without CPU instruction execution?
A) Polling (Programmed I/O)   B) Interrupt-driven per byte   C) DMA Burst Mode   D) DMA Cycle Stealing Mode   E) Port-Mapped IN loop
Answer: D) DMA Cycle Stealing Mode.
DMAC steals individual bus cycles intermittently so both the NIC transfer and CPU proceed smoothly without holding the bus exclusively (unlike Burst mode) and without per-byte CPU interrupts!
Q22 · Scenario In virtual-to-physical translation with a 4 KB page size on a 32-bit system, which bits of a 32-bit virtual address pass completely unchanged directly into the physical address?
A) Top 20 bits (VPN)   B) Bottom 10 bits   C) Bottom 12 bits (Page Offset)   D) All 32 bits   E) Middle 8 bits
Answer: C) Bottom 12 bits (Page Offset).
Because Page Size = Frame Size = 4 KB = 212 bytes, the lower 12 offset bits are identical in both virtual and physical addresses — enabling parallel TLB lookup alongside L1 cache indexing (VIPT)!
Q23 · Scenario Two 4-core CPUs execute the same C benchmark. CPU-A runs at 4 GHz with CPI = 2.0 and compiled IC = 10 × 109 instructions. CPU-B runs at 3 GHz with CPI = 1.2 and IC = 8 × 109. Which CPU finishes faster, and what are their execution times?
A) CPU-A (2.5s vs 3.2s)   B) CPU-B (3.2s vs 5.0s)   C) Equal (4.0s)   D) CPU-A (1.25s vs 2.4s)   E) CPU-B (2.0s vs 4.0s)
Answer: B) CPU-B (3.2 s) beats CPU-A (5.0 s)!
TimeA = (10×109 × 2.0) / (4×109) = 5.0 s.
TimeB = (8×109 × 1.2) / (3×109) = 3.2 s! Clock frequency alone (4 GHz vs 3 GHz) loses to better IPC and lower instruction count.
Q24 · Scenario Adding more hardware bus masters to a shared PCI-like bus uses Daisy-Chaining arbitration. What operational risk threatens the lowest-priority device positioned farthest from the arbiter?
A) Over-voltage   B) Cache coherence crash   C) Starvation during heavy traffic by upstream devices   D) Endianness flip   E) Double clock speed
Answer: C) Starvation of far devices (plus daisy propagation delay).
A bus grant signal stops at the first upstream requesting device; continuous upstream requests permanently starve downstream devices!

Part C: Exam Trick Questions & Classic Conceptual Traps (Q25–Q32)

Q25 · Trick In an 8-bit 2's complement ALU, adding (-5) + (+12) yields (+7) along with a hardware Carry-out bit Cout = 1. Did signed arithmetic overflow occur?
A) Yes, because Cout = 1 always indicates overflow   B) No! Carry-out Cout is ignored in 2's complement; overflow requires Cin(MSB) ≠ Cout(MSB)   C) Yes, result becomes -7   D) Only in 1's complement   E) Undefined
Answer: B) No overflow!
Trap alert: In unsigned addition, Cout = 1 means overflow. In signed 2's complement, 11111011 (-5) + 00001100 (+12) = (1)00000111 (+7) has BOTH Cin(MSB)=1 and Cout(MSB)=1 → 1 ⊕ 1 = 0 (zero overflow!).
Q26 · Trick What is the 4-bit Gray code equivalent of decimal 9 (Binary 1001)?
A) 1001   B) 1110   C) 1101   D) 1010   E) 0110
Answer: C) 1101.
Conversion: G3 = B3 = 1; G2 = 1⊕0 = 1; G1 = 0⊕0 = 0; G0 = 0⊕1 = 1 → 1101!
Q27 · Trick An expanding-opcode CPU has 16-bit instructions and 4-bit register addresses. There are 14 three-register instructions (OP R1, R2, R3). How many maximum two-register instructions (OP R1, R2) can it encode (leaving at least 1 prefix for 1-reg)?
A) 2   B) 16   C) 31 (up to 32 if zero 1-reg)   D) 64   E) 256
Answer: C) 31 (or 32 max without further expansion).
3-register uses 3 × 4 = 12 addr bits → 4 opcode bits = 16 patterns. Using 14 leaves 2 free prefixes, each expanding across the freed 4-bit register slot: 2 × 24 = 32 two-register slots!
Q28 · Trick Which statement about CPU Pipelining is FALSE?
A) Ideal throughput approaches 1 instruction per cycle   B) Split L1 I/D caches prevent IF/MEM structural hazards   C) Pipelining reduces the execution latency of a single isolated instruction   D) Branch misprediction flushes in-flight instructions   E) Clock period is bound by slowest stage
Answer: C) FALSE — single-instruction latency does NOT decrease!
Adding latches and balancing to the slowest stage actually makes a single lone instruction take slightly longer end-to-end; pipelining accelerates aggregate throughput across streams of instructions!
Q29 · Trick On a Write-Through cache with No-Write-Allocate, why is a Dirty Bit unnecessary in cache tag metadata?
A) Cache blocks never change   B) Main RAM always receives every write immediately, so RAM is never stale relative to cache   C) Valid bit acts as dirty bit   D) Direct mapping doesn't support writes   E) TLB stores dirty flags
Answer: B) RAM stays continuously up-to-date on every write.
Only Write-Back caches defer RAM writes and therefore require a Dirty (Modified) bit to know whether an evicted block must be written back to RAM!
Q30 · Trick In a level-triggered JK Flip-Flop with J = 1, K = 1, what happens if the clock HIGH pulse width exceeds the gate propagation delay?
A) Outputs lock at 0   B) Illegal undefined state   C) Race-Around Condition (output oscillates continuously between 0 & 1 during clock HIGH!)   D) Hold previous value   E) Destroys register
Answer: C) Race-Around Condition!
Fixed in hardware using a Master-Slave JK configuration or edge-triggered clock!
Q31 · Trick A 0-address (Stack) machine executes arithmetic using postfix expression AB+CD+*. How many memory/register address fields appear inside its ADD and MUL arithmetic instructions?
A) Two addresses   B) One implicit AC + one addr   C) Zero explicit address fields (operands come implicitly from Top-of-Stack)   D) Three addresses   E) Variable
Answer: C) Zero explicit address fields.
Only PUSH X and POP Y carry an address field; arithmetic/logic opcodes operate silently on top two stack elements!
Q32 · Trick Increasing a 64 KB cache from Direct-Mapped to 8-Way Set Associative (same total cache size & block size) causes which change to address bit fields?
A) Offset shrinks by 3 bits   B) Index shrinks by 3 bits and Tag grows by 3 bits   C) Tag shrinks by 3 bits   D) Index grows by 3 bits   E) Address width shrinks
Answer: B) Index shrinks by 3 bits, Tag grows by 3 bits.
Going from 1-way to 8 = 23-way reduces the number of Sets by factor 8 (s' = s - 3). Block Offset stays constant (block size unchanged), so those 3 freed Index bits move directly into the Tag!
