History, Pioneers & Supercomputers

  • Abacus: Earliest known calculating device (ancient China, ~4,000+ years ago).
  • Key Pioneers: John von Neumann (Father of modern computer architecture) | Robert Heath Dennard (Inventor of DRAM/RAM) | John McCarthy (Father of AI).
  • Key Firsts: 1st Stored-Program Computer = EDSAC | 1st Electronic Spreadsheet = VisiCalc | 1st Chatbot = ELIZA.
  • Speed Units: CPU = MIPS (Million Instructions/sec); Supercomputer = FLOPS (Floating-Point Ops/sec; 1 ExaFLOP = 1018 FLOPS).
  • India's Supercomputers: First = PARAM 8000 (1991, C-DAC); Top = Shakti Cloud (#35 Nov 2026 TOP500) & AIRAWAT (C-DAC Pune, #75 in 2023).
  • Digital Divide: Gap between populations with access to modern ICT / e-governance services and those without.

Ch 2: Hardware, CPU, Ports, Audio Jacks & Keyboard Keys

Start Here A CPU executes Fetch–Decode–Execute inside its Core(s), storing ALU results in the Accumulator. Know all legacy & modern ports (SATA, PATA, AGP, Parallel, HDMI, USB), 3.5mm audio jack colors, and keyboard key categories (Toggle, Modifier, Sticky).

CPU, Power & Logic Gates

  • CPU Core & Cycle: Basic computation unit = Core. Cycle: Fetch → Decode → Execute.
  • Registers & ALU: Register = group of flip-flops. ALU output is stored in the Accumulator.
  • Universal Logic Gates: NAND and NOR.
  • Firmware & SMPS: Firmware = hardware + software in ROM (e.g., BIOS — runs hardware check during booting). SMPS = Switch Mode Power Supply.
  • Peripheral Card: Hardware that puts info in and out of a computer (input/output devices).
  • Dumb Terminal: Only a keyboard and screen (no local processing).

Input, Output & Keyboard Key Categories

  • Dual I/O & Readers: Modem = Input + Output | OMR = bubble sheets | MICR = bank cheques | OCR = printed text.
  • Laser Printer: Uses dry toner powder. Speed = PPM (Pages/Min); Quality = DPI (Dots/Inch).
  • Toggle Keys (3): Caps Lock, Num Lock, Scroll Lock (give sound/LED cues).
  • Modifier Keys: Ctrl, Shift, Alt (never perform an action alone).
  • Sticky Keys: Accessibility feature letting you press combination keys (e.g., Ctrl+Alt+Del) one by one; enable by pressing Shift 5 times.

Ch 3: Memory Hierarchy, Storage Units, Timing & Number Systems

Start Here Primary Memory (RAM/ROM) sits closest to the CPU; Virtual Memory extends RAM using the Hard Disk. Memorize SRAM vs DRAM, HDD timing (Access time vs Latency), the full Byte-to-Yottabyte ladder, and number conversions.

Primary (Semiconductor: RAM & ROM) & Virtual Memory

MemoryBuilt From / MechanismKey Exam Facts
SRAM (Static RAM)Flip-flops (transistors)Faster, less power, expensive; used for Cache & Registers.
DRAM (Dynamic RAM)Transistors & CapacitorsSlower, more power (needs refresh); Main RAM (speed in MHz, DDR = Double Data Rate).
Cache MemorySRAM, 2nd fastest, Random AccessLocality of Reference. CPU↔Cache = Word transfer; Cache↔RAM = Block (cache line).
CMOS (NVRAM)Non-Volatile RAM (battery-backed)Stores BIOS settings & system clock.

Virtual MemoryPart of Hard DiskUsed by OS as an extension of RAM when physical RAM fills up.

Secondary Storage (Auxiliary Memory) & HDD Timing

  • Disk Formatting: Dividing a disk into Tracks & Sectors.
  • HDD Timing: Seek Time = time taken to move read/write head to the track on hard disk; Latency = time taken for request/response to hard disk.
  • Optical Discs (CD/DVD): Store data as Pits and Lands. CD-ROM (Read-only), CD-R (Write once), CD-RW (Rewritable).
  • Floppy Disks (IBM): 3.5" = 1.44 MB | 5.25" = 360 KB–1.2 MB | 8" = 80 KB–1.2 MB.

Number Systems, ASCII & Complements

  • Character Codes: ASCII = 7-bit (128 chars); Extended ASCII (EASCII) = 8-bit (256 chars).
  • Conversions: Any base → Decimal (positional powers: (1101)₂ = 13, (1F)₁₆ = 31); Dec → Bin (divide by 2, bottom-up: (45)₁₀ = 101101); Bin ↔ Oct/Hex (group by 3 / 4: 110101 → (65)₈ / (35)₁₆); Dec Fraction → Bin (multiply by 2, top-down: 0.625 → .101); Bin Fraction → Dec (left-to-right 2⁻¹, 2⁻²...: (101.101)₂ = 5.625).
  • Complements & BCD: 1's = flip bits; 2's = scan right-to-left, keep up to first 1, flip left bits (11001100 → 00110100). BCD = 4-bit per decimal digit (94 → 1001 0100).
  • 8-Bit Ranges: Unsigned = [0, 255]; Signed = [-128, +127].

2. Which binary power equals 1 Zettabyte (ZB) and 1 Yottabyte (YB)?ZB = 2⁷⁰ (10²¹); YB = 2⁸⁰ (10²⁴).
3. Where does Virtual Memory physically reside?On the Hard Disk (secondary storage).
4. What is CMOS also known as?NVRAM (Non-Volatile RAM).

Ch 4: Operating Systems, Booting, File Systems & Linux Commands

OS Basics, Windows Sequence & Booting

  • OS Structure: Hardware → Kernel → Shell → Applications. On booting, OS loads into RAM.
  • Open-Source OS: GNU/Linux, FreeBSD, Android, Chromium OS, OpenSolaris. Kali Linux = security/pen-testing; Linux default browser = Mozilla Firefox.
  • MS Windows Sequence: ME → XP → Vista → 7 → 8 / 8.1 → 10 → 11. (Windows 2000 = business/client-server focused; Windows 8 had no Start button).
  • Drivers & Utilities: Device Driver = software controlling a hardware device. Disk Defragmentation = consolidates fragmented HDD files.
  • Booting & Power: Cold Boot (Hard Boot) = from power-off | Warm Boot (Soft Boot) = restart while powered on | Random Rebooting (rebooting on crash) | Sleep (RAM, fast) | Hibernate (Disk, least power).

IEEE 802 Standards & Addressing

StandardTechnologyAddress / Spec
IEEE 802.3Ethernet (Wired LAN)MAC: Globally unique, 48 bits (6 bytes, 6 groups of 2 hex digits, colon-separated): First 6 = OUI; Last 6 = NIC
IEEE 802.4 / 802.5Token Bus / Token RingIPv4: 32 bits (dotted decimal, DARPA); A (large), B (medium), C (small) = Unicast; D = Multicast (one-to-many); E = Experimental / Broadcast (D/E have no default mask)

  • TCP/IP: Foundation of the Internet and most home/business networks.
  • Network Scope: Intranet = private network within an organization | Extranet = private network granting controlled access to external 3rd parties/partners.
  • Internet Milestones: Father = Vint Cerf; Mother = Radia Perlman. World launch = Jan 1, 1983; India = Aug 15, 1995. IP blocks assigned by IANA to RIRs. APIPA (169.254.x.x) when DHCP fails.
  • Topologies & Devices: Tree = Hierarchical; Bus = most data collisions. Router (connects LANs/subnets) | Gateway (dissimilar networks; also called Proxy server, NOT Firewall) | Bridge (2 ports, same network) | Repeater (fixes signal attenuation).

Protocols, Email, Cookies & Browsers

  • SMTP & MIME: SMTP sends text only; MIME (Multipurpose Internet Mail Extensions) enables attachments.
  • Gmail & Email Clients: Gmail (Application layer webmail, NOT desktop client): 25 MB max attachment, 500 emails/day free send limit, 15 GB free inbox, 5s Undo Send. Blacklisted emails → Spam. Desktop clients = Outlook, Thunderbird, Apple Mail.
  • Web & Protocols: Cookies = originally designed for server-side programming (state management). Spider (Web Crawler) = program used by search engines to index websites. SNMP (UDP 161) | ARP (IP→MAC) / RARP (MAC→IP) | PGP (Port 11371).
  • Browsers & Social: Engines: Chrome/Opera → Blink | Firefox (open-source) → Gecko | Safari → WebKit | IE → Trident. Tor (The Onion Router — dark web) | Epic (Indian Chromium-based browser by Hidden Reflex) | Qmamu (Indian privacy-focused search engine) | AltaVista (Yahoo) | LinkedIn (May 5, 2003, Reid Hoffman & Eric Ly; owned by Microsoft).

Languages, Compilers & Software

  • Language Firsts: First High-Level Language = FORTRAN (Formula Translation) | First Object-Oriented (OOP) Language = Simula | First AI Language = LISP.
  • Compiler: System software that converts entire source code to object code (machine code).
  • Patches: Vendor-created program modifications released to fix bugs or security vulnerabilities.
  • Licensing/Types: Shareware (Trialware) = free trial then paid | Bloatware = pre-installed unwanted resource-heavy software.
  • Extensions: PDF = Portable Document Format (non-editable by default) | WordPad = .rtf | MS Paint Bitmap = .bmp.

DBMS Basics

  • Database Hierarchy (Smallest → Largest): Bit < Byte < Field < Record < Table < Database (DB) < DBMS.
  • 5 SQL Sub-Languages: DDL (Definition), DML (Manipulation), DCL (Control), TCL (Transaction), DQL (Query).
